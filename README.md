# manual-Opus-v2

Manual técnico interativo desenvolvido na collab entre eu (@LPratesC) e o (@GVScode) como exercício prático para aprender e aplicar conceitos de HTML semântico e CSS moderno. O projeto demonstra como criar documentação navegável usando apenas HTML e CSS.

🎯 Objetivos de Aprendizado

- Estruturação semântica HTML5
- CSS Grid para layouts complexos
- Navegação por âncoras
- Responsividade com media queries
- Variáveis CSS
- Pseudo-classes (:target, :hover)

🛠️ Tecnologias

- HML5 - Estrutura do documento
- CSS3 - Estilização e layout (Grid, Flexbox)
- CSS Variables - Gerenciamento de temas
