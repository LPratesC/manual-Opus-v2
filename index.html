1. Introdução

Este Manual destina-se a orientar o programador/analista de sistemas que irá utilizar o OPUScase para a geração de rotinas.

1.1 Introdução ao OPUScase

O OPUScase é um produto do tipo I-CASE (Integrated Computer Aided Engineering). Permite aos profissionais de informática desenhar e gerar aplicações de forma rápida, fácil, segura, livre de erros de sintaxe e auto-documentada.

O OPUScase é composto de:

  • Dicionário de Dados
  • Editor de Telas de Entrada/Saída
  • Linguagem 4GL em português
  • Gerador de Rotinas em linguagem C
  • Gerenciador de Banco de Dados
  • Documentador de Manuais

1.4 Como Interpretar a tela de uma rotina

As rotinas geradas pelo OPUScase seguem a padronização SAA-CUA. Exemplo de layout:

+---------------------------------------------------------------+
| OPÇÃO  MENU  IDENTIFICA  AJUDA                                |
+---------------------------------------------------------------+
| PRGID: NOME DA APLICAÇÃO             TTY-DD                   |
|                                                               |
|  [ÁREA DE TRABALHO / LAY-OUT DA ROTINA]                       |
|                                                               |
|                                                               |
+---------------------------------------------------------------+
| Mensagem:                                                     |
| F01=AJUDA  F03=SAÍDA  F10=AÇÃO  F12=ELIMINA                   |
+---------------------------------------------------------------+

2. Dicionário de Dados

Dicionário de Dados é o conjunto das definições e especificações dos atributos e entidades, únicos no sistema.

2.1 Atributo

Atributo é a designação dada a uma informação determinando o formato e suas consistências.

Elementos da especificação de um atributo:

Banco
Caractere alfabético identificador do projeto ao qual o atributo está vinculado.
Atributo
Forma reduzida da identificação. Até 7 caracteres alfanuméricos, começando por letra.
Denominação
Nome do atributo. Até 30 caracteres.
Tamanho
Define a quantidade de caracteres do atributo.
Fixo/Variável
Define o tipo de atributo fixo (F) ou variável (V).
Formato
A (Alfabético), N (Numérico), D (Data), H (Hora), E (Qualquer), V (Valor).

3. Comandos

A linguagem OPUScase contém inúmeros comandos que podem ser usados pelo programador na criação de rotinas. Cada comando realiza ações definidas pelos argumentos e operadores associados.

Relação de Comandos Principais

Comandos mais utilizados na coluna de Procedimentos Lógicos
Comando Propósito
APAGA Eliminar todas as informações de uma entidade vinculadas ao nível informado.
CHAIN Verifica a existência de um registro em disco através de acesso direto.
COMPUTE Realiza cálculos matemáticos com variáveis.
DECLARA Declarar as variáveis de trabalho que a rotina irá usar.
EXIBE Exibir o conteúdo de cada atributo definido como EXIBIDO.
FACA Atribuir valores a uma variável (Ex: FACA A = "128").
SE Condicionar todos os comandos dentro de um bloco ao resultado afirmativo.
VERPRO Verificar a existência do próximo registro de uma entidade.

Exemplo de Sintaxe: Comando SE

SE VALOR = 10
    MENSAGEM "Valor é igual a 10"
    FACA TOTAL = TOTAL + VALOR
FIM

4. Biblioteca de Funções

O OPUScase dispõe de uma biblioteca própria de funções (libadis.a) que podem ser utilizadas em uma rotina através da coluna SUBROT.

  • UDEI: Converte data externa (DD/MM/AA) em data interna.
  • UDIE: Converte data interna em data externa.
  • UHEI: Converte horas externas em hora interna (segundos).
  • UHIE: Converte hora interna em hora externa.
  • YFF: Executa a operação de nova folha impressa (Form Feed).
  • WCAB: Executa a operação de impressão do cabeçalho padrão durante relatórios.

5. Gerador de Rotinas

O gerador de rotinas é usado para criar, editar, montar/compilar, documentar e testar rotinas.

Fases do Desenvolvimento:

  1. Manutenção do Cadastro de Rotinas
  2. Desenha Lay-out de Entrada
  3. Lay-out de Saída (Desenha e Agrega Atributos)
  4. Procedimentos Lógicos
  5. Gera e Compila (traduz para linguagem C)
  6. Executa Programa

Nota Importante sobre Diretórios

É aconselhável que cada rotina esteja armazenada em um diretório organizado:

  • Fonte OPUScase: ./src
  • Fonte C gerado: ./c
  • Programa executável: ./exec
  • Arquivos de dados: ./dados
