1. Introdução

Bem-vindo ao Manual Opuscase! Este sistema foi desenvolvido para facilitar a gestão de acordos comerciais, clientes e produtos de forma integrada e eficiente.

Neste manual, você encontrará informações detalhadas sobre todas as funcionalidades do sistema, desde a instalação até as operações mais avançadas.

Objetivos do Sistema

  • Gerenciamento completo de acordos comerciais
  • Controle de clientes e CNPJs
  • Cadastro e acompanhamento de produtos
  • Geração de relatórios personalizados
2. Instalação

Para instalar o Opuscase em seu ambiente, siga os passos abaixo:

Pré-requisitos

  • Servidor com PHP 7.4 ou superior
  • MySQL 5.7 ou superior
  • 2GB de RAM disponível
  • 10GB de espaço em disco

Passo a Passo

  1. Baixe o pacote de instalação
  2. Extraia os arquivos no diretório do servidor
  3. Crie o banco de dados MySQL
  4. Configure o arquivo config.php
  5. Acesse o instalador via navegador
  6. Siga as instruções na tela
3. Configuração

Após a instalação, é necessário configurar o sistema conforme as necessidades da sua empresa.

Acesse o menu Configurações > Gerais para definir parâmetros como nome da empresa, CNPJ, endereço e demais dados cadastrais.
Configure os níveis de acesso para cada usuário do sistema através do menu Administração > Usuários.
O sistema permite integração com ERPs, sistemas de nota fiscal eletrônica e outras plataformas.

7. FAQ - Perguntas Frequentes

Como recupero minha senha?

Acesse a tela de login e clique em "Esqueci minha senha". Digite seu e-mail cadastrado e siga as instruções.

Posso acessar o sistema pelo celular?

Sim! O Opuscase é responsivo e pode ser acessado por qualquer dispositivo com navegador.

Como faço backup dos dados?

O backup é realizado automaticamente diariamente. Para backup manual, acesse Administração > Backup.

Quantos usuários posso cadastrar?

O número de usuários depende do plano contratado. Consulte seu contrato ou fale com nosso comercial.
